{{- /* Carousel of people. Usage in Markdown, right after the section heading: {{% people labelledby="le-persone" %}} ### Name **Role** Text… ### Next name … {{% /people %}} Every "### " block becomes a slide; dots, arrows and "1 of N" follow the number of people. Uses {{% %}} so the headings stay in the page outline and in the table of contents. Without JavaScript it is a horizontal scroller with snap points; scripts.js shows the controls. Never auto-advances. */ -}} {{- $it := eq .Page.Language.Lang "it" -}} {{- $parts := split (printf "\n%s" (trim .Inner "\n")) "\n### " -}} {{- $people := after 1 $parts -}} {{- $n := len $people }}
{{ range $i, $p := $people }}
### {{ $p }}
{{ end }}
